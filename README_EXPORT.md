# نسخة مشروع محمية زمول عيسى بن سعيد الخييلي

هذه الحزمة تحتوي على **كود المشروع كاملاً**، بما في ذلك واجهة الموقع، لوحة الإدارة، الخادم، مخطط قاعدة البيانات، وترحيلات قاعدة البيانات.

## التشغيل محلياً

1. ثبّت Node.js إصدار 20 أو أحدث و`pnpm`.
2. فك ضغط الحزمة ثم افتح مجلد المشروع في محرر الكود.
3. نفّذ `pnpm install` لتثبيت الاعتمادات.
4. جهّز متغيرات البيئة المطلوبة لقاعدة البيانات وتسجيل الدخول والتخزين، ثم نفّذ `pnpm dev`.

## فحوصات الجاهزية

استخدم الأوامر التالية قبل النشر:

```bash
pnpm test
pnpm check
pnpm build
```

## ملاحظات مهمة للنقل

لا تحتوي الحزمة على أسرار أو كلمات مرور أو ملفات `.env`. يتطلب تشغيل الموقع خارج بيئته الحالية تهيئة قاعدة البيانات، تخزين الصور والفيديوهات، وإعدادات تسجيل الدخول من جديد. ملفات الوسائط المخزنة في خدمة التخزين الحالية ليست جزءاً من الحزمة، لكن روابطها محفوظة في البيانات.
